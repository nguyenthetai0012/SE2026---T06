# APP-05 repository guidance

- Read the relevant GitHub Issue and repository documentation before making changes.
- Follow the confirmed project scope. Ask the team when a required design decision is missing; do not choose a technology, protocol, schema, database, or framework on its behalf.
- Keep implementation work within the APP-05 project. Do not add or mix in individual assignment RE-022/R22.
